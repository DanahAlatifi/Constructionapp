# تطبيق المقاولات — بلس تك (React Native / Expo)

تطبيق إدارة مشاريع مقاولات، عربي بالكامل (RTL)، بثيم أخضر زيتوني مطابق للتصميم.
بيانات وهمية داخلية (mock) — جاهز لربطه بـ Odoo أو REST API لاحقاً.

## التشغيل على Expo Go

```bash
npm install
npx expo start
```

بعدها امسح الـ QR من تطبيق **Expo Go** على الآيفون (لازم يكون الجوال والجهاز على نفس الشبكة).
لو ما اشتغل عبر LAN جرّب:

```bash
npx expo start --tunnel
```

## ملاحظة مهمة عن RTL

التطبيق يفعّل `forceRTL`. أول مرة يفتح على Expo Go قد يحتاج **إعادة تحميل مرة وحدة** (هزّ الجوار → Reload)
عشان يطبّق الاتجاه العربي بشكل كامل. هذا طبيعي في Expo Go.

## الهيكل

```
src/
├── theme/        نظام الألوان والمسافات (غيّر الثيم من هنا)
├── data/mock.js  كل البيانات الوهمية — استبدلها بنداءات API
├── components/   مكونات معاد استخدامها (Card, StatusBadge, ProgressBar...)
├── screens/      الشاشات
└── navigation.js التبويبات + الستاك
```

## الشاشات

- **الرئيسية**: ملخص اليوم، أنواع المشاريع، رسم بياني، المشاريع الجارية
- **المشاريع**: قائمة مع فلاتر (الكل / قيد التنفيذ / مكتمل)
- **تفاصيل المشروع**: التقدم، البيانات المالية، المراحل، المستخلصات
- **المستخلصات**: الدفعات المرحلية
- **المزيد**: مقاولو الباطن، الضمانات، القوائم الإضافية
- **الملف الشخصي**

## الربط بالباك اند لاحقاً

كل البيانات في `src/data/mock.js`. عند الربط:
1. حوّل الدوال لـ async تجيب من الـ API.
2. استخدم state/loading في الشاشات مكان الاستيراد المباشر.
3. نمط الاستجابة جاهز مطابق لمخرجات مقاولات عادية.
